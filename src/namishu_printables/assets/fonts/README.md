# 内置字体

## 汉字字体

`NotoSansSC-Light.ttf` 为 Noto Sans SC Light，版本 2.004-H2，版权归 Adobe（2014–2021）所有，
保留字体名称为 Source。文件从原有 Namishu 项目迁入，未作修改。
上游项目为 [Noto CJK](https://github.com/notofonts/noto-cjk)，完整许可见 [OFL.txt](OFL.txt)。

## 拼音卡字体

`pinyin-regular.ttf` 为[宝宝字帖拼音字体](https://github.com/jaywcjlove/pinyin-font)的常规体，
版权归王楚江（2024）所有，保留字体名称为 `pinyin` 和 `宝宝字帖拼音字体`。
使用上游发布的原始文件，包含拼音字母、ü 和声调字符，完整许可见 [pinyin-OFL.txt](pinyin-OFL.txt)。

来源：[字体下载](https://jaywcjlove.github.io/pinyin-font/pinyin-regular.ttf)。

两款字体均采用 SIL Open Font License 1.1，随安装包提供并嵌入 PDF。
可以在各模块的 YAML 配置中指定其他字体。
